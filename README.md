# OVA · Capa de Internet del modelo TCP/IP

Objeto Virtual de Aprendizaje de Telemática (Ingeniería de Sistemas, Universidad de Córdoba).

**Integrantes:** Moises David Bernal Salazar · Tomas Antonio Ramos Diaz
**Docente:** Richard Crawford V.
**Herramientas:** HTML, CSS y JavaScript (sin dependencias)


## Contenido
- Inicio, 6 unidades con guías interactivas y cuestionarios (30 preguntas)
- Simulador de Ping/Traceroute (Unidad 5)
- 3 retos prácticos y 2 juegos educativos
- Evaluación final de 15 preguntas
- Bibliografía y créditos

## Referencias
Kurose y Ross, *Redes de computadoras: un enfoque descendente*; Forouzan, *Transmisión de datos y redes de comunicaciones*; RFC 791, 792, 1918, 2328, 2453, 4271, 4443 y 8200 (IETF).
